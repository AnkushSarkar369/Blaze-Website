# Assets to drop in

The site works without these. Where one is missing, a clean placeholder shows instead.

| File | Size | Used for |
| --- | --- | --- |
| `screenshot-main.png` | ~2400x1500, dark theme | "See it" section. Appears automatically once the file exists. |
| `screenshot-export.png` | ~2400x1500 | Optional second screenshot (not wired yet) |
| `og-image.png` | 1200x630 | Link previews. Update the `og:image` tag in `index.html` to an absolute URL once the domain is final. |
| `logo.svg` | square | Replace the inline mark in the nav/footer if you want a real logo. `favicon.svg` is a placeholder too. |
